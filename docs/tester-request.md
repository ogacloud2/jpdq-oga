# 試してもらう方へのお願い（依頼文のひな形）

公開前に、信頼できる数名に、別の環境で `jpdq_oga.selfcheck()` を実行してもらうための、依頼文です。
**リポジトリは非公開のため、試してもらう方には、ZIP を個別に渡します**（または、GitHub の閲覧権限を付けます）。

## 依頼文（そのまま使えます）

> お忙しいところすみません。日本向けのデータ品質チェック集「jpdq-oga」（Databricks の DQX 用）を作っており、
> 公開前に、いろいろな環境で動くかを確認したいです。**5〜10 分**で終わります。
>
> **やってほしいこと**
> 1. 添付の `jpdq-oga-0.1.0.zip`（**展開しないでそのまま**）を、Databricks の Volume にアップロードしてください。
> 2. ノートブックで、次の 3 つのセルを順に実行してください。
>    - `%pip install databricks-labs-dqx==0.16.0 openpyxl /Volumes/<カタログ>/<スキーマ>/<ボリューム>/jpdq-oga-0.1.0.zip`
>    - `dbutils.library.restartPython()`
>    - `import jpdq_oga` と `jpdq_oga.selfcheck()`
> 3. 表示された**出力の全文**を、そのまま貼って返信してください。エラーが出た場合は、赤いエラーの全文もお願いします。
>
> 画面つきの詳しい手順は、添付の `selfcheck.md` にあります。
>
> **お願いと注意**
> - 業務データは使いません。自己診断は、答えの分かっている固定の値だけで動き、表の読み書きはしません。
> - 出力には、バージョン情報と、固定値の判定結果しか含まれません。
> - もし可能なら、**お使いの環境**（Free Edition / 会社のワークスペース、Serverless / 汎用クラスター、DBR のバージョン）も教えてください。
